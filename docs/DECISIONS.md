## Проверенные технические факты

Проверено 22.11.2026 по npm и официальной документации. Перед использованием перепроверь: версии могли уйти вперёд.

| Что | Факт |
|---|---|
| Версии в npm | next 16.4.6, react 19.3.1, next-intl 4.15.3, tailwindcss 4.3.5, typescript 7.0.2, zod 4.6.7, vitest 5.1.1, @playwright/test 1.65.1, ioredis 6.0.0, @electric-sql/pglite 0.5.17, cmdk 1.1.1 |
| Next.js 16, требования | Node.js 20.9 или новее, TypeScript 5.1 или новее |
| Next.js 16, `proxy.ts` | Заменил устаревший `middleware.ts`. Файл лежит в корне или в `src`, экспортирует `proxy` или default, область задаёт `config.matcher` |
| Next.js 16, standalone | `output: 'standalone'` создаёт `.next/standalone`. Папки `public` и `.next/static` копируются туда отдельно. Запуск: `node server.js` с переменными `PORT` и `HOSTNAME` |
| Next.js и TypeScript 7 | `next build` проверяет типы через локальный `tsc`. У TypeScript 7 пока нет JS-API компилятора, поэтому совместимость линтеров нужно проверить до выбора версии |
| Сборка на Windows | Standalone-сборка использует симлинки и на Windows может получиться неперемещаемой. Образ собирается в Linux: в Docker или в CI |
| next-intl 4 | `defineRouting` с `locales` и `defaultLocale`, сегмент `[locale]`. На этапе 3: `src/proxy.ts` с `createMiddleware(routing)` |
| Caddy | `request_body { max_size }` отвечает 413. Глобальные опции `servers { trusted_proxies static ...; client_ip_headers ... }` дают плейсхолдер `{client_ip}` |
| finzli.com | Next.js за Cloudflare, редирект с корня на `/en`, `X-Frame-Options: SAMEORIGIN`, публичный changelog на `/en/updates` |

### Уточнения этапа 0 от 23.11.2026

- У версий `next-intl` 4.15.3 и Vitest 5.1.1 ещё не прошло семь дней с публикации, поэтому закреплены 4.15.1 и 5.1.0 соответственно. Точные версии всех установленных пакетов — в `pnpm-lock.yaml`.
- Для статических страниц `next-intl` читает локаль через стабильный `next/root-params` (Next.js 16.3+) вместо устаревающего `setRequestLocale`. `generateStaticParams` собирает три локали; остальные возвращают 404. Автовыбор языка, `proxy.ts` и редирект с `/` остаются на этапе 3.
- Playwright проверяет production-сборку: `pnpm start` добавляет статические ресурсы к standalone-артефакту. Переносимый артефакт для деплоя по-прежнему собирается на Linux.
- `agentRules: false` предотвращает автоматические правки `AGENTS.md` при `next dev`. Путь к справочнику установленной версии указан в самом `AGENTS.md`.

## Решения владельца по контенту от 23.11.2026

- Целевую должность пока не указываем. Для опыта, навыков, образования и языков используем Lebenslauf владельца.
- На сайте показываем email, телефон и фото из `Ich.jpg`. Контакты и исходный Lebenslauf в Git не добавляем; перед публикацией фото удаляем его метаданные.
- Для Finzli оставляем подтверждённый разбор вклада и ссылку на сайт. Скриншотов и записей экрана не будет.
- Владелец подтвердил, что SucheWohnung работает на VPS, и разрешил описывать эксплуатацию без секретов и данных доступа. Факты по обоим проектам собраны в `CONTENT.md`.
