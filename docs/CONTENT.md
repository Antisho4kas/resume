# Контент: модель и правила

## Модель

Единый источник: файлы резюме на трёх языках с одной схемой zod. Из них собираются страница, API, печатная версия и PDF, терминал, SQL-база и подпись. Формат файлов выбирает разработчик на этапе 1 и записывает в `DECISIONS.md`.

Разделы резюме: шапка (имя, фото, статус доступности, контакты), о себе, опыт, навыки по направлениям с уровнем, проекты, образование, языки. Целевую должность пока не указываем.

У навыка есть уровень и ссылки на подтверждения: проект, запись опыта или доказательство на сайте. На этих связях строится подсветка «навык — проект».

## Правила

- **Только подтверждённые факты.** Для опыта, навыков и их уровней, образования и языков используем Lebenslauf, указанный владельцем. Сведения о проектах уточняем по его подтверждениям. Не добавляем уровни или факты, которых нет в источниках.
- **Уровни не завышаются.** Если владелец называет навык основами, на сайте это основы.
- **Командная работа отделена от личной.** В командном проекте описывается только зона ответственности владельца.
- **Три языка равноправны.** Перевод передаёт тот же смысл. Немецкий текст вычитывается отдельно.
- **Личные данные.** На сайте показываем email, телефон и фото из `Ich.jpg`. Значения контактов не храним в репозитории или истории Git. Исходный Lebenslauf не публикуем.

## Проекты

### Finzli

- Публичное описание продукта: платформа аналитики крипторынка в реальном времени.
- Период: январь–декабрь 2024 года. Команда из двух человек.
- Вклад владельца: frontend и QA, прежде всего JavaScript, TypeScript и работа с API. Настраивал базу данных и хостинг на AWS, а также агента для анализа на Amazon Bedrock.
- Не приписываем владельцу разработку бэкенда, других аналитических компонентов или продуктовые решения.
- Из внешних материалов оставляем ссылку на `finzli.com`. Скриншоты и записи экрана не показываем; неподтверждённые записи changelog не связываем с вкладом владельца.

### SucheWohnung

- Личный проект владельца, публичный репозиторий `Antisho4kas/SucheWohnung`.
- По README репозитория: TypeScript, Node.js, NestJS, Prisma, BullMQ и Redis, Next.js, PostgreSQL с PostGIS, grammY, Docker Compose. Очереди collect, match, notify. По умолчанию активен только синтетический источник `mock`.
- По подтверждению владельца, проект работает на VPS. Можно описывать его развёртывание и эксплуатацию, не раскрывая секреты и данные доступа.
- На сайте используются только синтетические данные.

## Перед публикацией

- Для Finzli не предполагаем тип занятости. В раздел опыта проект добавляем только при подтверждении статуса. Не называем конкретные экраны, инструменты QA или сервисы AWS, кроме Bedrock, без подтверждения.
- На этапе 1 владелец подтверждает тексты на трёх языках.
