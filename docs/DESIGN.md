# Дизайн-направление

Основано на исследовании референсов в Lazyweb 22.11.2026: поиски по секциям и приёмам сайта, 15 экранов просмотрено. Новые визуальные решения сначала показываются владельцу прототипом.

## Принципы

- **Типографика вместо декора.** Имя служит главным визуальным элементом первого экрана. Под ним возможна короткая строка с проверяемыми фактами, без целевой должности.
- **Документ.** Редакционная вёрстка листа резюме. Ссылки на доказательства стоят внутри текста.
- **Плотность без перегруза.** Ощущение «много всего» создаёт однородная сетка мелкого текста, а не украшения.
- **Один акцент.** Бумажно-белый и почти чёрный плюс один акцентный цвет, который используется только для маркеров доказательств. Есть светлая и тёмная темы.
- **Два шрифта.** Один гротеск и один моноширинный, оба с латиницей и кириллицей. Шрифты раздаются с собственного домена.
- **Спокойное движение.** Анимация только функциональная, с учётом `prefers-reduced-motion`.

## Компоновка

- **Десктоп:** липкая колонка с именем, статусом, действиями «Скопировать email» и «PDF», переключателями языка и режима. Справа документ.
- **Мобильный:** колонка сворачивается в верхнюю панель.
- **Опыт:** changelog с периодами, группами пунктов и фильтрами по направлению.
- **Терминал:** рядом с ним кликабельный интерфейс, который его зеркалит. Рекрутёр кликает, инженер печатает.
- **Палитра команд:** группы действий, шорткаты, подсказка при первом визите.
- **Форма:** одна колонка, минимум полей, счётчик в углу поля, строка о приватности под полями.
- **Переключатель языка:** три языка в строку, названиями, без флагов.

## Чего избегаем

Шаблонного dev-портфолио: тёмно-синий фон, заголовок с градиентным словом, бейдж «Available for projects», иконка прокрутки. Пример такого шаблона: `devv.ai/code/preview/f80nf129a9kw`.

## Где референсов нет

Для трёх вещей близких примеров в библиотеке не нашлось. Их нужно проектировать самостоятельно и проверять прототипом:

- переключатель режимов «Рекрутёр / Инженер»;
- раскрытие доказательства прямо в строке документа;
- страница разбора проекта (находятся только корпоративные списки кейсов).
